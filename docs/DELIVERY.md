主要实验证据：

1. 独立代码对照案例，在小模型成本记零假设下，协同比全大模型强模型费用低 62.2%，产出程序耗时低 13.1%。双 API 原始口径同时保留；不是本地 GPU 实测，也不是多任务平均结论。
2. 原生 Agent 界面验收，真实小模型 7 次、强模型 2 次，Solve 候选被采纳，独立最终加速比 2.0454×。没有为这一次验收另跑两条单模型基线。

当前研究任务是三类预置基准，论文仍为合成材料；不是任意论文或用户代码的通用执行入口。计时校验也不构成面对恶意候选的完整可信边界，见项目 README 的已知局限。
